### Featured project

#### [security-headers-checker](https://github.com/Goco36/security-headers-checker)

A Python CLI that checks a URL for HTTP security headers and flags missing, misconfigured or information-leaking ones. JSON output, CI-friendly exit codes and unit tests.

```text
$ python -m hdrcheck http://localhost:8000

HEADER                       STATUS         SEVERITY
------------------------------------------------------
Strict-Transport-Security    missing        high
Content-Security-Policy      missing        high
X-Content-Type-Options       missing        medium
Server                       leak           info
```
